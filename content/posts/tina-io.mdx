I work at [SSW](https://www.ssw.com.au), which builds TinaCMS, so a lot of my week goes into tina.io. The site is built with Tina itself, which is the useful part: we hit the editor's rough edges before customers do, then fix them in the product.

## The homepage

Every page on tina.io is a stack of blocks that the marketing team can edit and rearrange without a developer. I've built a fair few of them, including the comparison box, the testimonials, rich text in the feature cards, and the markdown block below. I also did a pass over every page title.

## AI search readiness

[tina.io/geo](https://tina.io/geo) is a free tool I built. You paste in a URL and get a graded report on how ready the page is for search engines and AI answer engines: whether AI crawlers can reach it, the search basics, structured data, and newer things like serving markdown to agents. It lives in its own repo and project, and tina.io proxies it under `/geo`, the same way it does TinaDocs.

## TinaDocs

[TinaDocs](https://tina.io/tinadocs) is a docs starter built on Tina. Clone it and every page is already editable in the visual editor, with nothing to set up. I worked on most of what sits inside the pages: tabbed code blocks, recipe blocks, type definitions, file structure embeds and a Monaco code editor. I also did the theme selector and dark mode.

<AnnotatedImage src="/uploads/posts/tina-io-recipe.webp" alt="A TinaDocs page showing a recipe block, a numbered list of steps beside a block of React code" caption="A recipe block in the TinaDocs starter." aspect="16/10" notes={[{ text: "each step lights up its lines", x: 37, y: 37.5, mark: "circle", side: "bottom", size: 18 }]} />

Search is Pagefind, so it's static and needs no server. The index is built at build time, so I added a check when the dev server starts that warns you if it's gone stale.

## Plus the boring bits

There's plenty of upkeep too. I added visual regression tooling to catch UI changes, wrote AGENTS.md so AI coding agents can find their way around the repo, removed old dependencies and kept the docs current.
